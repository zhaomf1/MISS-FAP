# 应用逻辑与上板验证

## 文件职责

- incubator_model.c：无 HAL、RTOS、LVGL 依赖的计时状态机；内部时长使用毫秒。
- app_service.c：20ms 业务任务，消费 UI 命令；协调计时、温控请求、电机和提醒，发布互斥保护的状态快照。
- temp_service.c：独立温控通信任务，每轮完成后延时500ms，执行 Modbus 查询和设温。通信重试不会阻塞业务计时或 UI。
- temp_calibration.c：0.01℃有符号双向换算接口，当前原值返回；读取显示与写入控制各自经过一次对应转换。
- ui_layout.c：唯一活动界面、控件句柄、导航、编辑草稿、按键重复和状态显示。只在 uiTask 调用 LVGL。
- motor.c：保留现有脉冲控制协议，新增位置心跳时间查询。

旧版 ui.c、ui_ascii.c 和 ui_utf8.c 示例已清理；当前界面只由 ui_layout.c 实现，工程使用合并字库 lv_font_ui_font.c。

## 操作

上/下/左/右移动焦点，SET（KEY_OK）进入参数编辑，再次 SET 提交。

- 温度编辑：左/右选择十位、个位、十分位；数字下方短线标记所选位。上/下修改。按住上/下500ms后连续调整。
- 时间编辑：界面显示 `15.0 min` 一类数值，最小步长0.1min（内部6秒），范围0.1–99.9min；运行中显示分秒倒计时。
- 延迟编辑：1秒步长，0表示N，不自动转4℃。
- 右侧四格：左上开始、右上停止、左下开/关盖、右下消音。
- SET 提交温度后显示 SETTING，收到SV和温控使能的成功响应后才确认。失败显示WRITE FAILED并保持报警。

## 本版明确采用的可配置策略

incubator_model.h 集中定义：温度4–60℃，时间0.1–99.9min，延迟0–300s，开始要求关盖。

温控首次给出有效读数后，应用会自动写入默认37.0℃设定值；若用户先手动设温，则以用户设定为准。开始前要求温控读数有效、无模块报警、设温写入已确认、舱门关到位且反馈新鲜。未强制要求到温或READY两分钟等待。

计时过程中开盖不暂停/中止计时。运行中温度与孵育时间设置锁定、延迟值仍可编辑；按停止可中止本轮，4℃保存时可重新设置温度以返回待开始。没有自动重启下一轮。

每轮启动时保存时间与延迟快照。孵育结束时置蜂鸣请求；延迟起点是本轮准确结束时刻，与消音时刻无关。N分支保持既有温度。延迟到期异步请求4℃；写入确认后显示降温，到温后显示保存。重新设温成功后进入下一轮准备。

到温以校正后的PV与已确认液体目标比较：进入±0.3℃，退出±0.5℃。通讯数据失效时不保留“已到温”判断。模块READY未接入；这不是READY状态显示。

## 外设与异常

- 温度单位0.01℃，读取按INT16S解释；用户目标通过 temp_calibration_to_module 转换后验证有符号16位范围。
- 完整温控轮询连续失败3次判离线；某次读取失败立即使当前PV无效；超过2500ms的旧数据也不作为实时值。
- 写入失败独立锁存，不因消音被清除；下一次成功写入解除。写入迟迟无结果时保持命令互锁，避免旧事务未完成又发送新SV。
- 正常时ALM呈灰色；温控离线、读数失效、模块报警、舱门故障或空闲到位心跳超过2500ms、写入失败时显示红色ALM，并在状态栏显示异常来源。运行或延迟计时在报警期间冻结，恢复后续计。命令拒绝原因显示在左下提示行。
- 上电不自动运动舱门。首次明确按开盖/关盖时，若尚未初始化，先执行安装自校准，再执行所选动作。自校准可能转动，需确保空间无阻挡。
- app_board_buzzer_set 为弱硬件接口，默认返回0且不操作任何GPIO。结束时UI显示待消音状态及BUZZER NOT WIRED；确认引脚后覆盖该接口。当前不会实际鸣叫。
- RS485沿用现有自动收发/弱DE接口和模块配置，不自动发送ASCII配置命令。
- 参数仅RAM保存；EEPROM型号、地址和保存策略未确认，不实现猜测性的掉电保存。

## 验证

本机运行测试：

1. test_incubator_model.c：tick回绕、运行参数快照、准确结束时间、消音不取消延迟、N分支、延迟调度和降温确认。
2. test_modbus.c：3700温度高低字节、负温、CRC和写入回显。修复了原transaction读取时丢失高字节的问题。
3. test_app_service.c：模拟异步外设确认、启动门禁、孵育结束/消音/自动4℃/下一轮流程。
4. check_reference_ui.py：合并字库映射、实际行高、25个静态标签边界/重叠及动态中文文案。

上板建议先设温确认，再关盖；孵育时间设0.1min、延迟设2s，检查约6s结束提醒及随后4℃设置。再把延迟改为N，检查本轮结束后不自动降温。最后测试温控断线、舱门反馈断线及恢复。

烧录不等于已验证外设；蜂鸣器实声、校正系数、温控模块使能状态和机械动作均需实际硬件确认。调试可查看 g_lvgl_diag 的RTOS剩余堆、UI栈余量和LVGL剩余堆，新增任务后以运行时数据验收。
